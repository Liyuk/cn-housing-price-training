# 审查记录：五年预测论文的算法（v0.2）——偏漏与优化空间

> 范围：`docs/paper-five-year-housing-price-forecast.md`（v0.2）及其实现 `src/five_year_forecast.py`。
> 方法：复现论文数字 → 读代码 → 在 2011 年起的更长历史上做滚动检验 → 核对引用。**全部可用 `python scripts/paper_algorithm_audit.py` 复现**（输出 `reports/paper_algorithm_audit.json`）。
> 与已有的 `review-five-year-housing-price-forecast.md`（v0.1→v0.2 自查）不重复：那份修的是文字与数据口径，这份查的是算法本身。
> 本文只记录发现，**不修改论文正文**（论文双仓维护，见 `docs/project.md`）；代码里只加了一个默认关闭的开关，v0.2 仍可逐位复现。

## 结论速览

按"对论文结论的影响"排序：

1. **实现错误：均值回归的衰减因子用反了（影响北京头条数字）。** `src/five_year_forecast.py:74,79` 用 `1 − ρ` 当保留系数，等于每月只保留 `1−ρ` 的缺口，也就是**第一步就闭合了 ρ 的缺口**（全国 96%，北京 69%）。"均值回归"成分实际是"直接跳到样本均值"，论文报告的半衰期（16.1 与 1.9 个月）不是模型在用的。修正后北京权重由 0.25/0.50/0.25 变为 0/0.75/0.25，**五年基准由 −4.6% 变为 −7.0%**，区间由 −9.0%~−0.1% 变为 −11.5%~−2.6%；全国不变（回归权重为 0）。
2. **全国 −22.1% 本质是"最近 12 个月动量外推 60 个月"，而权重只在 7 个重叠窗口里选出。** 这 7 个窗口跨度 2022-01 至 2024-06，只相当于 2.5 个独立的 12 个月，全部处于同一轮下行；全国第一名与第二名的误差只差 0.6%，北京只差 0.1%（`reports/paper_algorithm_audit.json: selection`）。选择目标是"12 个月环比指数的 MAE"，被拿去报告"60 个月累计变化"。
3. **在更长历史上滚动检验，论文算法远期不如"价格不变"，北京所有期限都不如。** 起点 2016-06 至 2021-09（22 个）：全国 +12/+24 个月比"不变"好 30%/16%，+36/+60 个月差 7%/36%；北京 +12 至 +60 个月差 40%/48%/80%/223%；论文区间的实际覆盖率只有 14%–50%。
4. **论文自己引的文献不支持"五年动量外推"。** Glaeser–Nathanson 的结论是"一年期动量、五年期均值回归"；Case–Shiller 发现下一年的变化只有今年的四分之一到二分之一；论文对 60 个月用的是 100% 动量。
5. **季节性成分没有价值，且论文引的 Case–Shiller 恰恰说季节性证据弱。** 代码取"去年同月"这一个带噪声的观测；改成多年、多城市汇总的季节剖面，滚动回测里 +1 个月误差反而更大（0.302 对 0.297）。
6. **均值回归的锚是样本均值，结论随窗口变化。** 2019 年起窗口的月均环比 99.80（年化 −2.45%），2011 年起 100.01（年化 +0.09%）。同一个"回归到长期均值"，在论文窗口里意味着继续下跌，在更长窗口里意味着持平。
7. **区间不是误差区间。** 低/高情景的幅度 = 0.5 ×｜过去 5 年累计变化｜（`five_year_forecast.py:146-150`），与预测误差无关；论文又写"更可能的区间"，读起来像概率。
8. **遗漏：没有任何基准、没有转折点检验、没有指数度量讨论。** 论文没有和"价格不变"之类的基准比较；没有检验算法在 2014、2021 这样的转折点表现；把国家统计局 70 城的等权平均当作"价格"，没有讨论指数本身的度量问题。

**论文做得好的地方**（审查的公平性）：数字能完整复现（见下）；明确说基准是动量外推、不代表强判断；给了权重敏感性表，并且自己发现了北京权重的不稳定；给出情景而不是单一点预测；有自查记录。

## 2. 偏漏

### 2.1 代码与论文不一致（错误）

**(a) 均值回归衰减因子。** 见结论 1。证据：`src/five_year_forecast.py:74` `speed = 1.0 − rho`，`:79` `nv = long_mean + (anchor − long_mean) * speed`。AR(1) 的偏差每月应乘 ρ。数值对照（`/tmp` 脚本，已并入测试 `tests/test_update_and_forecast.py::PaperReversionTests`）：

| | 第一步闭合的缺口 | AR(1) 应闭合 |
|---|---|---|
| 全国（ρ=0.958） | 95.8% | 4.2% |
| 北京（ρ=0.695） | 69.5% | 30.5% |

影响：全国回归权重为 0，头条不变；北京头条变化见结论 1。**论文中"全国回归半衰期 16.1 个月、所以是趋势市"这条解释链也随之失去依据**：模型并没有用 16.1 个月的回归速度。

**(b) AR(1) 的中心与回归的目标不一致（小问题）。** `estimate_reversion`（`:54`）对"偏离 100 的偏差"回归，而回归目标是样本均值。全国按样本均值居中后 ρ = 0.939（半衰期 11.1 个月，不是 16.1）；北京几乎不变（0.693）。

**(c) "延续最近 12 个月均值"并不是常数（描述不准）。** 论文 §3.2 的公式 `mean(mom[-12:])` 在预测第 2 步起，窗口里混入了预测值（`:144` 把基准值追加进历史），所以趋势成分是一个递推：全国 −22.1% 而不是常数 99.516 的 −25.3%，北京纯趋势下 −9.6% 而不是 −24.5%。效果上让最近几个月的权重更大，对北京近期的好转更敏感，但论文没有说明。

### 2.2 方法弱点

**(a) 权重选择的样本过小、目标不一致。** `:102` 取前 75% 做选择，`:108` 的 `range(36, train_end − 12 + 1, 3)` 在 90 个月上只剩 7 个起点（2022-01 起，评估到 2024-06）：7 个窗口每 3 个月一个、每个 12 个月长，高度重叠，只相当于 2.5 个独立年份。第一名与第二名：全国 0.2973 对 0.2989（差 0.6%），北京 0.6144 对 0.6149（差 0.1%）——"北京是均值回归市"建立在 0.1% 的差距上。选择目标是 12 个月 MoM 指数的 MAE，对复利累积的偏差不敏感：每月 0.05 点的偏差，60 个月就是 3%。论文的敏感性表其实已经露出这一点：北京在切点 0.8 处整体翻成纯趋势。再加上头条数字：

| 切点 | 北京权重 | 北京五年基准 |
|---|---|---|
| 0.55 / 0.6 / 0.7 | 0 / 0.75 / 0.25 | −2.3% |
| 0.75（论文） | 0.25 / 0.5 / 0.25 | −4.6% |
| 0.8 | 1 / 0 / 0 | −9.6% |
| 0.9 | 0.5 / 0.5 / 0 | −0.6% |

仅选择这一个超参数就让北京头条在 −0.6% 到 −9.6% 之间摆动，**比论文给出的低/高区间（−9.0%~−0.1%）还宽**。全国：切点 0.55 选出纯季节性（−25.3%），其余都是 −22.1%。

**(b) 没有抗转折点的机制。** 趋势成分不衰减。检验见下一节：在 2016–2021 的上涨期起点，它把动量外推成极端值。

**(c) 区间构造。** `:146` `hist_factor` = 过去 60 个月环比连乘，`:148` `half_width = 0.5 × |1 − hist_factor|`，再均匀摊到 60 个月（`:151-152`）。幅度由"过去 5 年发生了多大变化"决定，与预测误差无关，也不随期限变化。

**(d) 样本只含一轮下行。** 90 个月全部在 2019 年之后，包含一次完整下行和很短的前期；没有一个转折点可以用来检验"趋势还是回归"。

### 2.3 在更长历史上的滚动检验

`scripts/paper_algorithm_audit.py` 对 2011-02 起的全国与北京 70 城等权二手指数，在每个起点（2016-06 至 2021-09，每 3 个月，22 个）用**当时的数据**重新跑论文算法（重新选权重），再与随后实际发生的累计变化比较。"阻尼"是我自己的基准：EWMA 水平 × 0.96^h。

全国（累计变化的平均绝对误差，百分点）：

|---|---|---|---|---|---|
| +12 | 2.90 | 4.13 | 2.42 | +30% | 41% |
| +24 | 6.14 | 7.30 | 4.16 | +16% | 36% |
| +36 | 10.60 | 9.91 | 7.47 | −7% | 14% |
| +60 | 19.59 | 14.45 | 14.40 | −36% | 23% |

北京：

| 期限 | 论文算法 | 价格不变 | 阻尼趋势 | 论文 vs 不变 | 论文区间覆盖 |

| +12 | 6.65 | 4.76 | 6.90 | −40% | 41% |

**局限，必须说清楚：** 起点全是 2016–2021 年的上涨期，被检验的是"从上涨期外推到随后的下行"，不是论文实际面对的"下行期外推"；22 个起点高度重叠，+60 个月时有效独立起点只有 1 个左右；北京在这段时期有 2016–2017 的政策冲击，对任何动量类算法都不友好（阻尼趋势在北京同样不如"不变"）。所以这些数字说明的是**算法在转折点上没有保护**，不能直接换算成"论文的 −22% 一定错"。

新模型在 +12、+24 个月的误差约为论文算法的一半（全国）或明显更低（北京）；**+36 个月起两者都不优于"不变"**，+60 个月更是如此（新模型自己的回测里 +48、+60 个月比"不变"差 12% 与 33%）。所以五年期预测没有被证明的技能，只能当情景。

### 2.4 遗漏

- **没有基准。** 论文没有把算法与"价格不变"或任何朴素方法比较，读者无法判断 −22% 比什么好。
- **没有转折点评估，没有概率。** 论文用"驻底"情景讨论转折，但没有模型内生地给出转折的可能性。
- **指数度量。** 论文把国家统计局 70 城的**等权平均**当作"价格"（`:47` `groupby("month").mean()`），没有讨论指数是否反映真实价格、等权是否合适。文献里有专门研究中国指数构建的工作（Wu, Deng & Liu 2014，J. Real Estate Finance & Economics 48(3)：522–545，DOI 10.1007/s11146-013-9416-1）；Fang 等（2016）自建了 120 城新房价格指数。**这两篇我只核实了文献存在，没有取得摘要，不对其结论作判断**；但"指数质量"至少应该作为一项局限写入。
- **基本面。** 论文已承认（§5 局限二），宏观面板仅 3.5 年。补充：租金收益率等变量这次已采到 12 个城市 2022 年起的月度数据，仍不足以估计长期关系。

## 3. 优化空间

状态：**已实现**（在 `src/probabilistic_forecast.py`，经同一套滚动回测）/ 已测未采用 / 未做。

| 问题 | 改进 | 状态与结果 |
|---|---|---|
| 衰减因子用反 | 保留系数改为 ρ | `five_year_forecast.py` 加 `ar1_fix` 开关，默认关闭以保证 v0.2 可复现；北京 −4.6% → −7.0% |
| 选择目标与报告量不一致；样本小且重叠 | 对每个期限单独、只用当时已实现结果学习；+12 个月后不再学习 | 已实现：+12 个月误差比"不变"低 38% |
| 趋势不衰减 | 阻尼趋势（0.96/月）。系数在 0.90–0.96 之间几乎不敏感；**1.0（不阻尼，接近论文）明显更差**：+36 个月误差 14.1 对 12.0 | 已实现 |
| 单个城市动量噪声大 | 向所属层级（一/二/三线）的均值收缩，λ=0.6：+12 个月误差 −5%，+6 至 +36 个月一致下降 | 已实现（λ 从三个取值中选，略偏乐观） |
| 季节性无价值 | 删除 | 已测：汇总季节剖面 +1 个月误差更大，其余期限无差别 |
| 区间不是误差区间 | 宽度 = 月度波动×√期限 + 趋势不稳定度×期限；取近期加权的历史误差分位数 | 已实现：80% 区间覆盖 +12 个月 80%、+24 个月 82%（论文算法的低/高带只有 36%–41%） |
| 窗口太短 | 用 2011 年起的数据做滚动检验；建模起点提前到 2006 | 已测：提前到 2006 对预测无改善（旧口径、前两年环比与同比不自洽，现行 2008-01 起） |
| 基准缺失 | 每个期限都报告"相对价格不变"的改善与区间覆盖 | 已实现，网站"预测逻辑"页 |
| 五年期 | 保留，但仅作情景；论文基准 −22.1% 落在新模型 80% 区间 −24.3%~+3.5% 的低端 | 已实现（新模型五年中位数 −6.5%）；**无被证明的技能** |
| 指数度量、基本面锚、转折点概率、外生政策变量 | — | **未做**；需要新数据来源（成交价、租金、收入）或政策事件库，这次没有可靠的批量来源 |
| 层级协调（城市→层级→全国）、在线共形校准 | — | 未做；预期主要改善远期区间覆盖 |
