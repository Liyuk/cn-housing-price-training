# 可接入数据源清单

本项目的主键建议统一为 `region`、`month/year`、`market`，并为每个来源保留 `source_url`、`retrieved_at`、`methodology`。不同来源不应只按名称拼接，必须先核对统计口径、时间频率和覆盖范围。

## 第三优先级：解释变量与稳健性检查

- 国家统计局城市统计年鉴：GDP、人口、居民收入、就业、财政、公共服务、交通等年度城市特征。
- 各城市统计年鉴/统计公报：北京和重庆区县级人口、收入、产业、固定资产投资等年度变量。
- 自然资源部门土地供应/成交公告：与土地市场网交叉核对，避免单一来源漏项。
- 住房租赁网签备案数据：可用于租售比、租金压力和替代需求，但各城市开放程度差异很大。

## 建议的接入顺序

1. 先接国家统计局房地产开发和销售数据，形成全国月度宏观特征表。
2. 再接 LPR 和土地成交数据，加入融资成本与供给预期。
3. 接北京网签数据，验证交易量特征对价格的增量解释力。
4. 接重庆年鉴年度表；若住建委能提供稳定的区县网签表，再建立北京/重庆区级模型。

## 不能直接混合的口径

- 2008—2010 的“房屋销售价格指数”与 2011 年起现行住宅价格调查方案不同，应保留 `methodology=legacy/current`。
- 国家统计局 70 城价格是指数，不是每平方米成交单价；网签面积/金额计算出的均价也不等于同口径价格指数。
- 北京经纪机构数据代表上报机构，不等于全市场；重庆公告中的中心城区也不等于全市或所有区县。
