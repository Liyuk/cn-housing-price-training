# 城市—区—房价变化与预测项目计划

## 最终目标

构建一个可持续更新的中国房地产分析系统，覆盖：

- 城市层：新房、二手房价格指数与成交/销售变化；
- 区级层：网签、成交面积、挂牌/租金和可获得的区级价格；
- 因素层：利率、人口、收入、就业、土地、库存、开工和政策；
- 输出层：趋势分析、区域比较、影响因素解释和未来预测。

## 执行节点

1. **数据源核验**：确认公开页面、开放接口、下载文件的可用性、更新频率和合规边界。
2. **统一数据字典**：统一城市、区、月份、市场类型、单位、来源和统计口径。
3. **行政区映射**：建立城市—区县—行政区代码表，处理改名、撤并和别名。
4. **城市级价格**：采集国家统计局70城新房/二手房月度指数及历史补充数据。
5. **城市级成交与供给**：接入房地产开发投资、销售面积/额、开工、竣工和库存代理变量。
6. **区级交易**：采集北京、重庆及其他城市住建部门公开的网签套数和成交面积。
7. **挂牌与租金**：优先使用授权、公开下载或可验证的开源数据；安居客/链家/贝壳只在许可范围内采集。
8. **土地与政策**：加入住宅用地成交、土地溢价、限购/贷款/税费等政策事件。
9. **数据清洗**：去重、单位换算、异常检测、缺失标记、来源优先级和版本留痕。
10. **描述性分析**：城市和区级趋势、同比/环比、波动、分化、成交量集中度和新二手联动。
11. **特征工程**：滞后项、滚动均值、季节性、供需比、利率变化、政策窗口和空间邻接特征。
12. **基准预测**：季节性基线、移动平均、ARIMAX/动态回归和面板回归。
13. **机器学习预测**：Random Forest、Gradient Boosting、LightGBM（环境允许时）和面板模型。
14. **时间滚动回测**：只使用预测时点之前的数据，比较不同预测期限和不同城市/区域。
15. **关系与解释**：相关性、滞后相关、固定效应、Permutation Importance/SHAP（适用时），明确相关不等于因果。
16. **报告与更新**：自动生成Markdown/CSV/图表，记录最新月份、数据质量和不能推断的结论。

## 当前数据可行性判断

| 层级 | 首选数据源 | 可获得字段 | 当前状态 |
|---|---|---|---|
| 城市价格 | 国家统计局70城 | 新房/二手房环比、同比、定基/平均指数 | 已有解析器，持续补历史 |
| 城市二手房价格 | 中国房地产估价师与经纪人协会 | 70城二手住宅月度指数 | 已接入2023样本，历史文件待继续解析 |
| 区级交易 | 北京住建委等地方住建部门 | 网签套数、成交面积、月份 | 北京已接入单月样本 |
| 宏观 | 国家统计局、人民银行 | 销售、投资、开工、LPR、收入、人口 | 已有解析器框架 |
| 土地 | 中国土地市场网及地方公共资源交易平台 | 宅地成交、楼面价、溢价率 | 待按城市接入 |
| 挂牌/租金 | 有授权的商业数据、公开研究数据、合规公开页面 | 挂牌价、租金、库存代理 | 待核验；不绕过反爬或登录 |
| 行政区 | 国家统计局/民政公开行政区划及开源镜像 | 区县代码、名称、层级 | 待加入标准表 |

## 重要口径

国家统计局70城指数是城市层面的价格指数，不能直接当作区级成交单价。区级模型必须使用区级数据；如果某个城市只有区级成交量而没有区级价格，只能做成交活跃度分析，不能声称已经完成区级房价预测。
