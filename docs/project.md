# 中国 70 城住宅价格指数项目说明

> 一个可复现的房价数据与研究项目：从国家统计局公开月报构建 70 城住宅价格指数面板，用可解释的机器学习方法给出五年预测，并把"数字能告诉我们什么 / 不能告诉我们什么"显式编码进数据。

## 在线演示

**趋势看板（GitHub Pages）：** <https://liyuk.github.io/cn-housing-price-training/>

看板把项目的数据、方法与预测结果可视化：70 城榜单（寒/凉/平/温/热、趋势强度、12 个月预测与概率）、自 2011 年的走势与未来 36 个月概率预测、止跌信号与同比热力图、**预测成绩单**（回测优势、区间覆盖率、预测账本）、北京/重庆区县情景、官方区级网签，以及宏观背景（LPR、开发投资、待售面积）。所有图表由仓库数据预生成（`site/data/*.json`），全静态、无后端；数据口径在页面"口径说明"弹层中完整声明。

## 项目定位

本项目不是"猜房价涨跌"的黑箱，而是把房价分析拆成三个可审计的层次：

1. **数据**：来源—口径感知地构建可复现的房价数据资产，显式标注每个字段的来源分级（官方 / 行业指数 / 公开第三方 / 派生）、口径切换与泄漏控制；
2. **方法**：可解释的组合预测——每个预测数字都能拆解为若干可理解成分的加权，权重由数据在滚动验证中自己决定；
3. **边界**：明确声明模型不知道什么——基准是纯价格动量的外推，情景区间不是概率分布，模型无法内生预测"底"。

## 方法与预测

**可解释三成分组合**（趋势延续 + 均值回归 + 季节性），权重由滚动 12 个月样本外 MAE 在 0.25 步长网格上选择，仅用决策时点之前的历史，避免数据窥探。权重本身即解释：

| 市场 | 数据选出的权重 | 市场类型 | 回归半衰期 |
|---|---|---|---|
| 全国 70 城 | 趋势 1.0 | 下行趋势市 | 16.1 个月 |
| 北京 | 回归 0.50 / 趋势 0.25 / 季节 0.25 | 均值回归市 | 1.9 个月 |

五年预测（2026—2030）基准情景：全国累计约 **−22%**，北京约 **−4.6%**。情景区间按历史 5 年实际波动锚定，全国更可能的区间为 **−5% 至 −22%**，北京为 **−5% 至 +5%**。数据同时显示驻底领先信号（全国环比连续两年改善、北京环比已转正），因此"若驻底成立"的替代情景显著收窄。区间**不代表概率分布**。

**2026-11 升级（网站与代码已切换到新模型；论文 v0.2 的数字不变）**：70 城 × 60 个月概率预测取代"全国/北京两条路径"成为看板主预测。全国中位数 +12/+24/+60 个月分别为 **−2.8% / −4.5% / −6.5%**（+12 个月 80% 区间 −6.3% ~ −0.4%；五年 −24.3% ~ +3.5%）；回测里 80% 区间在 +1 至 +24 个月的实际覆盖率为 77–82%，+12 个月比“价格不变”准 38%；+13 个月起的点预测是固定的收缩阻尼趋势，**+48、+60 个月比“不变”还差 12%、33%，五年期只作情景**。论文 v0.2 的算法经审查发现一处实现错误（均值回归衰减因子用反，北京五年基准 −4.6% 应为 −7.0%）和若干方法问题，在相同起点上误差约为新模型的两倍，详见 [`review-forecast-paper-algorithm-2026-11.md`](review-forecast-paper-algorithm-2026-11.md)；v0.2 对 2026-07..09 的实战核对见 [`research-2026-11-upgrade.md`](research-2026-11-upgrade.md) §4。新模型每次更新都冻结预测、下期自动评分（`reports/forecast_ledger/`）。

## 运行

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python -m unittest discover -s tests -v   # 测试
.venv/bin/python -m src.collector --start-year 2008 --end-year 2026   # 采集
.venv/bin/python -m src.five_year_forecast          # 五年预测（v0.2，论文版）
bash scripts/monthly_update.sh                      # 每月更新：抓数据 → 概率预测 → 重生成看板数据 → 测试
.venv/bin/python -m src.district_forecast           # 区级预测
.venv/bin/python -m src.report                      # 分析报告
.venv/bin/python scripts/build_demo_data.py         # 重新生成 demo 数据
```

本地预览 demo：在 `site/` 目录下 `python3 -m http.server 8080`，访问 <http://localhost:8080>。

## 边界声明

- 价格指数是**指数**，不是每平方米成交价；区级价格为**挂牌代理**，非官方成交价；
- 宏观面板为**年初累计口径**的同比，与单月同比不可直接比较；
- 预测为**纯价格时间序列的动量外推**，不纳入政策、宏观基本面等外生变量；
- 情景区间按历史波动锚定，**不是概率分布**。
