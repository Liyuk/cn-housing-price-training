# 中国 70 城住宅价格指数项目说明

> 一个可复现的房价数据与研究项目：从国家统计局公开月报构建 70 城住宅价格指数面板，用可解释的机器学习方法给出五年预测，并把"数字能告诉我们什么 / 不能告诉我们什么"显式编码进数据。

## 在线演示

**交互式预测看板（GitHub Pages）：** <https://liyuk.github.io/cn-housing-price-training/>

看板把项目的数据、方法与预测结果可视化：五年情景区间（低/基准/高）、可解释三成分的权重与逐月分解、70 城分化热力图、单城走势、北京/重庆区县挂牌价情景、官方区级网签，以及宏观背景（LPR、开发投资、待售面积）。所有图表由仓库数据预生成（`site/data/*.json`），全静态、无后端；数据口径在页面"口径说明"弹层中完整声明。

## 项目定位

本项目不是"猜房价涨跌"的黑箱，而是把房价分析拆成三个可审计的层次：

1. **数据**：来源—口径感知地构建可复现的房价数据资产，显式标注每个字段的来源分级（官方 / 行业指数 / 公开第三方 / 派生）、口径切换与泄漏控制；
2. **方法**：可解释的组合预测——每个预测数字都能拆解为若干可理解成分的加权，权重由数据在滚动验证中自己决定；
3. **边界**：明确声明模型不知道什么——基准是纯价格动量的外推，情景区间不是概率分布，模型无法内生预测"底"。

## 数据资产

| 数据集 | 覆盖 | 来源分级 |
|---|---|---|
| 70 城二手官方指数 | 2019-01 – 2026-06，连续 90 个月，无缺口 | 官方（NBS） |
| 70 城新住宅指数 | 2022-10 起（2023-02—07 有缺口） | 官方（NBS） |
| 全国宏观面板 | 2023-02 – 2026-06，35 个月累计口径（投资/开工/竣工/销售/待售/资金） | 官方（NBS） |
| LPR 序列 | 2019-08 – 2026-07，84 个月 | 官方（央行） |
| 北京区级挂牌均价 | 2025-01 – 2026-06，10 核心城区 × 18 个月 | 公开第三方（creprice） |
| 北京官方区级网签 | 2025-10 横截面，17 区，13,595 套 | 官方（住建委） |
| 北京年度交易 | 2020 – 2024 | 官方（住建委） |

关键发现：中房学（CIREA）公开的二手指数与官方数据在 3,990 个重叠单元上逐格一致（r = 1.0000），说明行业指数是官方转载而非独立来源——独立核验的边界在于"哪里没有第二个来源"。

## 方法与预测

**可解释三成分组合**（趋势延续 + 均值回归 + 季节性），权重由滚动 12 个月样本外 MAE 在 0.25 步长网格上选择，仅用决策时点之前的历史，避免数据窥探。权重本身即解释：

| 市场 | 数据选出的权重 | 市场类型 | 回归半衰期 |
|---|---|---|---|
| 全国 70 城 | 趋势 1.0 | 下行趋势市 | 16.1 个月 |
| 北京 | 回归 0.50 / 趋势 0.25 / 季节 0.25 | 均值回归市 | 1.9 个月 |

五年预测（2026—2030）基准情景：全国累计约 **−22%**，北京约 **−4.6%**。情景区间按历史 5 年实际波动锚定，全国更可能的区间为 **−5% 至 −22%**，北京为 **−5% 至 +5%**。数据同时显示驻底领先信号（全国环比连续两年改善、北京环比已转正），因此"若驻底成立"的替代情景显著收窄。区间**不代表概率分布**。

## 运行

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python -m unittest discover -s tests -v   # 测试
.venv/bin/python -m src.collector --start-year 2008 --end-year 2026   # 采集
.venv/bin/python -m src.five_year_forecast          # 五年预测
.venv/bin/python -m src.district_forecast           # 区级预测
.venv/bin/python -m src.report                      # 分析报告
.venv/bin/python scripts/build_demo_data.py         # 重新生成 demo 数据
```

本地预览 demo：在 `site/` 目录下 `python3 -m http.server 8080`，访问 <http://localhost:8080>。

## 边界声明

- 价格指数是**指数**，不是每平方米成交价；区级价格为**挂牌代理**，非官方成交价；
- 宏观面板为**年初累计口径**的同比，与单月同比不可直接比较；
- 预测为**纯价格时间序列的动量外推**，不纳入政策、宏观基本面等外生变量；
- 情景区间按历史波动锚定，**不是概率分布**。
